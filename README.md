# Monorepo - Task Management

Este repositório contém o backend (Laravel) e frontend (Angular) do sistema de gerenciamento de tarefas.

## Estrutura

```
.
├── backend/          # API Laravel
├── frontend/         # Aplicação Angular
├── package.json      # Configuração raiz do monorepo
└── README.md
```

## Backend (Laravel)

A API está localizada em `backend/`. Consulte `backend/README.md` para mais detalhes.

## Frontend (Angular)

A aplicação frontend está localizada em `frontend/`. Consulte `frontend/README.md` para mais detalhes.

## Próximos passos

Para fazer push para o GitHub:

```bash
git push -u origin main --force
```

⚠️ **Atenção**: Como você mudou a estrutura do repositório, será necessário usar `--force` para sobrescrever o histórico remoto. Certifique-se de que ninguém mais está trabalhando neste repositório antes de fazer o push.
